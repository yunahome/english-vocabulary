# PRD：背单词小程序

## 产品定位

一款面向碎片时间的背单词微信小程序。第一阶段只搭建可运行的技术骨架：前端能拉取真实后端数据，后端能持久化到 PostgreSQL。

## 里程碑

### M0：工程骨架（当前阶段）

- [x] pnpm monorepo：小程序 / 后端 / 共享类型 / 数据库 / 文档
- [x] uni-app + Vue 3 + TypeScript + Vite + Pinia
- [x] NestJS + Prisma + PostgreSQL + REST
- [x] 健康检查接口与单词列表/新增接口
- [ ] 接入微信登录
- [ ] 记忆算法与复习计划
- [ ] 腾讯云 COS 音频/图片存储
- [ ] 部署到腾讯云轻量应用服务器

## 核心用户流程（待实现）

1. 进入小程序，看到今日待复习单词。
2. 点击单词查看释义、例句和发音。
3. 标记「认识 / 模糊 / 不认识」，更新熟悉度。
4. 系统按遗忘曲线安排下次复习。
